# PM Academy Onsite #1 — PM Responsibilities

> "The complete set the PM owns before a phase can close." Access layer only; the PDF in `original/` remains the preserved source of record.

Three streams (columns of the grid, applied across all five phases): **Client Experience** (CONFIDENCE) · **Team Leadership** (PEOPLE) · **Business Management** (RESULT).

## Pursuit & Contracting

**Client Experience**
- Client success criteria defined
- Decision-makers identified
- Expectations documented
- Sample contract reviewed in Go/No-Go

**Team Leadership**
- Delivery leadership engaged
- Risk posture aligned
- Consultant proposals requested
- Revit model started

**Business Management**
- Fee estimate completed
- Proposal submitted
- Contract executed
- Go/No-Go completed & logged
- Project number opened (project not under contract); time charged to the correct phase
- Pursuit logged in CRM

## Initiation & Planning

**Client Experience**
- Kickoff completed with client
- Communication cadence established
- Project risks communicated
- External kickoff held — deliverables, schedule & milestones confirmed
- Preliminary concept defined

**Team Leadership**
- Project team assigned
- Roles & responsibilities communicated
- Internal kickoff completed
- Project Storyteller named; A3 initiated
- BIM environment (Forma / ACC) set up & users added

**Business Management**
- Fee & schedule composed (Budgeting Spreadsheet)
- Project budget established
- Schedule approved
- Project set up in BST — budget, phasing & staffing
- Staffing schedule submitted
- Client & consultant contracts executed and filed to 01_Contracts
- Project workspace created in Centerline

## Design & Coordination

**Client Experience**
- Design direction approved
- Milestone approvals obtained
- Client concerns addressed
- Program & guiding principles defined with client
- Scope reviewed vs. contract; amendments requested as needed

**Team Leadership**
- Consultants aligned
- Coordination process established
- Technical reviews completed
- BIM Execution Plan established & kickoff held
- Specifications developed; code analysis completed
- Drawings & specs published
- QC peer review vs. deliverables; Bluebeam archived

**Business Management**
- Forecast completed
- Budget & schedule variance reviewed
- Percent complete updated
- Variance reviewed each accounting cycle — burn, hours, billings
- Phase cost estimates provided (SD / DD / CD)
- Phase archived at completion

## Construction Admin

**Client Experience**
- Scope changes managed with client
- Additional services authorized
- Construction issues communicated
- Contractor recommendation issued to client
- Pre-construction meeting held; Notice to Proceed issued
- AIA instruments issued — ASI, CO, CCD, Substantial Completion

**Team Leadership**
- Staffing reviewed each phase in BST; A3 updated; consultants added to Centerline
- Construction support assigned
- Resources adjusted to workload
- Quality reviews completed
- Bid process run — Bid Management, Pre-Bid Conference, addenda, tabulation
- RFIs & submittals processed
- Field reports filed
- Construction Management set up in Centerline

**Business Management**
- Additional services logged
- Invoices submitted
- Profitability reviewed
- Owner/Contractor agreement requested & executed
- Contractor pay applications reviewed
- Metrics & pre-bill review completed

## Closeout & Growth

**Client Experience**
- Final client feedback obtained
- Completion confirmed
- Future opportunities identified
- Punchlist created & completed in Centerline

**Team Leadership**
- Lessons learned completed
- Knowledge transferred to team
- Project A3 finalized for future marketing

**Business Management**
- Financial closeout completed
- AR resolved
- Project records archived
- Project emails stored in Centerline
- Centerline archive zip requested (project archived)
