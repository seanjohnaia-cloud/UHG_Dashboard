# Contracts Module — Development Branch

Status: development / prototype

Purpose: project-level contract/SOW intelligence branch for preserving contract source context, identifying Service Order/SOW gaps, tracking authorization boundaries, and preventing contract-specific requirements from becoming general DIF guidance without Risk Management review.

Promotion requirement:

- Contract source mapping reviewed.
- Scope, fee, schedule, assumptions, exclusions, and carry-forward items remain source-backed.
- Project-level contract evidence stays distinct from Portfolio contract governance.
- Risk Management routing is defined for liability, authorization, and scope-drift issues.
- User approves interaction model and verification record.
