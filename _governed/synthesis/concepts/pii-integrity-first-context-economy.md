# Integrity-First Context Economy (Philosophical Level)

Non-authoritative synthesis. The principle layer beneath the tiered-context architecture (`pii-tiered-context-architecture.md`). These are commitments, not mechanisms.

## 1. Integrity precedes economy

The industry optimizes context economics for cost — token budgets, model-tier routing, cache rates. Pii inverts the ordering: **project integrity first, nothing else; economies as a consequence of good structure.** Cheap context loading that pulls the wrong slice is worse than expensive loading that pulls the right one. The economies are real and unexplored, but they are found *inside* the integrity structure, not traded against it.

Corollary (the user's formulation): the system must be known to do **what it can actually do, not what one wants it to do**. Every architectural claim carries a capability-honesty boundary: which parts are deterministic bookkeeping (trustable now) and which parts require model judgment (not yet trustable for integrity-bearing decisions).

## 2. Admissibility and relevance are the same computation

Governance metadata (status, provenance, supersession, admissibility) was designed to answer "what may be trusted, for what purpose, with what standing." Context loading asks "what deserves to be in the window for this query." These are the same question run for different purposes — which is why the governed tree, built for authority, turns out to be the load-bearing structure for context economy. This is not a coincidence to be noted but a design principle to be exploited: **structure built for trust doubles as structure for attention.**

The human analogy that generated the tier model: people carry a cheap resident *map* (what exists, what state it's in, where records live) and load depth on demand, routed by the map. Day-to-day operations and researching an 8-year-old project are different context modes, and a human knows which one they're in. The archaeologist doesn't hold the old project in mind — only the knowledge that it exists, is closed, and where its records are.

## 3. Depth is decided by structure, not by confidence

A model's sense that it "probably remembers enough" is precisely the thing that cannot be trusted; models are poor at knowing what they don't know. So escalation to deeper context is triggered by structural signals — field states (`conflict`, `assumed`), citations to decision records — never by model self-assessment. Metadata decides; the agent obeys; only a human may overrule structure toward shallowness.

## 4. Continuity lives in the record, not in the agent

No agent's memory is the project. Project continuity is externalized in the governed tree; any agent, at any time, hydrates from it. Model-native memory remains working context, never project record (constitutional). Multi-agent partitioning follows from this: nobody re-remembers everything, because nobody ever held everything. The unsolved remainder is *conversational* continuity — the live thread of reasoning — which is real, valuable, and constitutionally standing-less; how to preserve it cheaply without promoting it is an open question, not a settled answer.

## 5. Concurrence is safeguard and accountability rolled into one

Anything that loads into every query is load-bearing, whatever its layer label says. Automated updates to load-bearing context are model output promoted to ground truth — forbidden in effect even when permitted in form. The human concurrence gate is not process overhead; it is the point at which accountability attaches to state. And because it is a gate, it emits its own telemetry: who is processing updates, how fast, how deeply. Unreviewed updates are governance debt with a timestamp.

## 6. Gates die by rubber-stamping, not by being skipped

The observed failure mode of review gates is not defiance but decay: concurrence becomes throughput, the gate still "exists," the metrics stay green, and judgment has left the room. Therefore the burden of keeping the gate alive falls primarily on the **proposer**: diffs not documents, consequence ranking, provenance pre-attached, honest staleness. Making concurrence cheap enough to stay real is integrity engineering, not UX polish. And gate metrics must measure health, not compliance — a queue cleared in 90 seconds flat is a worse sign than one cleared slowly.

## 7. Coherence is not correspondence

Every internal check the system can run — citation resolution, state consistency, supersession lineage — verifies **coherence**: record against record. None of it can verify **correspondence**: record against world. The screen can be perfectly coherent and perfectly wrong. The only ground-truth anchor in the architecture is a human standing in reality with a printout — the human-to-human audit. This is the field-verification instinct of professional QA/QC practice applied to an information system, and it is the layer most AI-system designs simply do not have.

Triangulation follows: approval streaks are deliberately ambiguous (clean proposals and dead gates look identical); the reality audit disambiguates them. Measured dialogue invites Goodhart — so effectiveness is defined by outcome (did the comment change the record? did gate corrections reduce audit misses?), never by volume.

## 8. Findings must re-enter, or the loop is theater

An audit finding that lives on a printed sheet is decoration. A finding that lands as a source record, drives a `conflict` state, and flows through the same pending→concur pipeline is the system's immune memory. The general form: **every watcher's output is itself a governed record**, so the control system feeds itself — tiered context watched by the gate, the gate watched by metrics, metrics watched by the audit, the audit feeding back into the record. Each layer watches the one below; the top layer is a human in the field.

## 9. The through-line

From the session that produced this page: rejected branches are evidence, not exhaust; inter-agent messages have no standing until governed; delegation of work is not delegation of authority; the system performs bookkeeping while humans exercise judgment at gates. All of these are one commitment stated in different registers — **machine speed for mechanics, human judgment for authority, and visible structure connecting the two.**
