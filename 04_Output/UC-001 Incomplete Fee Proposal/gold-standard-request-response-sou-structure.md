# Gold Standard Output — Request + Response Statement of Understanding

## Purpose

The client-sent matrix artifact provides the requested fee/schedule data, but the gold standard should also include a **scope section**. The complete output should function as a shared statement of understanding:

```text
Your Request + Our Response = Complete Statement of Understanding
```

## Required Sections

### 1. Request Summary

Purpose: restate what UHG asked for, in plain project language.

Minimum contents:

- project name/location;
- source request date/reference if available;
- requested activity;
- project-only focus, if narrowed;
- no-Service-Order / preliminary fee-exercise status;
- Grace-only / no-MEP-currently status.

### 2. Scope Understanding

Purpose: state what Grace understands the project scope to include before showing the fee.

Minimum contents for Muncie:

- small remodel / clinic project size category;
- approximate area / area uncertainty;
- Research / Room 2091 storage and ambient drug study room scope;
- Room 2092 punch-door/security implication;
- x-ray / imaging planning scope;
- adjacency priority between dressing room and x-ray room;
- power/data/charging/printer/copier implications;
- finish/casework/shelving assumptions;
- RSI / x-ray equipment / vendor coordination assumptions;
- MEP excluded as consultant fee for this exercise but likely required later.

### 3. Grace Response / Fee Basis

Purpose: show how Grace is responding to the request.

Minimum contents:

- Schedule F / Clinic Project Size 0-2,500 SF basis;
- per-contract comparison total;
- proposed adjusted fee total;
- deliverable/phase matrix;
- explicit statement that this is not a formal Service Order today.

### 4. Assumptions

Purpose: make the proposal governable and prevent silent scope drift.

Minimum contents:

- ACAD backgrounds available for use;
- no MEP consultant fee included now;
- equipment vendor drawings to be provided when required;
- UHG/owner consultants provide security/IT/medical-equipment requirements as applicable;
- project can proceed as small-project fee exercise rather than formal Service Order at this stage.

### 5. Exclusions / Deferred Items

Purpose: separate current proposal from later project obligations.

Minimum contents:

- MEP consultant fee excluded;
- formal Service Order excluded today;
- final MEP/security/x-ray responsibilities deferred;
- unresolved owner/consultant/vendor requirements deferred;
- additional services not listed in the matrix excluded unless approved.

### 6. Schedule / SLA Understanding

Purpose: connect fee proposal to the time basis.

Minimum contents:

- proposed schedule days by phase;
- CD coordination footnote requiring minimum 15 business days when vendor drawings are required;
- owner review / vendor-data dependencies.

### 7. Carry-Forward / Next Step

Purpose: explain what happens if UHG accepts the pricing.

Minimum contents:

- fee/scope can be carried into Service Order documentation later;
- outstanding fields required for formal Service Order;
- future MEP consultant fee may be added if/when requested.

## Output Principle

A fee matrix alone answers **how much**.

The gold standard answers:

1. what UHG asked for;
2. what Grace understood;
3. how Grace priced it;
4. what is included/excluded;
5. what happens next.
