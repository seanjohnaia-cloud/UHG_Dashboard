# Post-Proposal Review Analysis — Reduced AOR Scope

## What Changed

UHG's latest response introduces a new project reality: the submitted fee proposals created enough information for internal review, but UHG now questions whether the full MSA deliverable path is required for these small projects.

The new proposed pathway is:

```text
Reduced AOR scope
→ primarily site due diligence
→ advance directly to 90% CD set
→ review and final comments
```

## Why This Matters

This challenges the earlier Service Order Development Matrix logic, which priced a more complete MSA/Schedule F phase path.

The discussion is no longer only:

```text
What is the right fee under Schedule F?
```

It is now:

```text
What reduced scope is contractually acceptable, professionally responsible, and fee/schedule appropriate?
```

## Key Issues for the Call

| Issue | Why It Matters |
|---|---|
| Reduced AOR definition | Need to define exactly which standard AOR services remain and which are omitted. |
| Site due diligence scope | Need to clarify whether this includes field verification, existing condition review, code/life-safety review, imaging/vendor coordination, security/power/data review, etc. |
| Direct-to-90% CD | Need to identify risks of skipping SD/DD/progress review gates. |
| Review/final comments | Need to define who reviews, what comments are expected, and whether one revision cycle is included. |
| Contract compatibility | MSA may allow out-of-sequence or adjusted scopes, but changes need clear written agreement / Service Order path. |
| Fee impact | Existing proposed $27,950 may need reallocation/reduction/reframing depending on omitted phases. |
| Schedule impact | Direct-to-90% may reduce elapsed time but increase risk if owner/vendor information is incomplete. |
| MEP / vendor dependencies | Even if no MEP fee now, x-ray/security/power/data requirements may still affect CD readiness. |

## Pii Lesson

Reality introduced a new state:

```text
post_proposal_scope_negotiation
```

The gold-standard response must be able to handle this state by comparing:

1. original request;
2. proposed fee response;
3. UHG's revised/reduced delivery concept;
4. contract/SLA/deliverable implications;
5. risk and professional responsibility.

## Immediate Working Position

Prepare for a call, not a revised fee yet.

The call should produce a clarified reduced-AOR scope definition before Grace revises scope, schedule, or fee.
