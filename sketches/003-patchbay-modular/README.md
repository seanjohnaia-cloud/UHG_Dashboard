## Variant: Modular Patchbay

### Design stance
Rack-mounted modular gear rather than a single console face — a rectangular screen module, a function-button module, a gauge-strip module, and a "patchbay" module for Perspective (jacks + faders), stacked as independent horizontal rows. Less "one big console," more "signal-routing rack" — closer to a professional audio patchbay than a war-room.

### Key choices
- Layout: stacked horizontal modules, each self-contained with its own header/border — mirrors rack-unit hardware, and scales by adding more rows/modules later
- Typography: Barlow Condensed for module headers/buttons, IBM Plex Mono for data — more "professional tool" than "vintage prop," slightly less costume-y than the other two
- Color: dark neutral rack with a single warm accent (orange) for active/primary state and a cool accent (cyan) for gauges/data — a two-color system instead of one
- Interaction: jacks toggle routing per Perspective, faders tune amplitude per Perspective plus one Master fader; function buttons sit beside the screen as a control strip

### Trade-offs
- Strong at: the "patchbay" framing directly matches your ask (turn on this and this, less on these two, one at 100%) as literal signal routing — probably the closest match to what you described; also the most extensible module system for adding portfolio-level or project-level rows later
- Weak at: least overtly "Cold War" of the three — reads more like modern studio/broadcast gear than a bunker; if the vintage-military feel is non-negotiable this one under-delivers on it

### Best for
The actual working session where Perspective-tuning is the main task, and you want the console metaphor to scale into a real information architecture (more rows = more modules) rather than stay a fixed single-screen prop.
