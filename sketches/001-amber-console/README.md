## Variant: Amber Command Console

### Design stance
Full brushed-steel command console, single central CRT screen (amber phosphor), physical toggle-switch + rotary-knob bank on the left for Perspective, radial gauge cluster on the right for quick-glance metrics. Closest literal read of "Cold War command center."

### Key choices
- Layout: 3-column console (Perspective bank | Screen + Functions | Gauges), rivets/bezel framing to sell the "physical panel" read
- Typography: Oswald (condensed display) for labels, Share Tech Mono for the screen — both read as military/industrial stencil
- Color: single amber accent on near-black steel; green/red only for status lamps and gauge danger states
- Interaction: knobs are draggable (mouse rotate), switches toggle on click, function buttons (Extract/Absorb/Elevate/Quarantine) log to a scrolling console log at the bottom — literally logs the governed-layer verb selected

### Trade-offs
- Strong at: instant "not a SaaS dashboard" read; ties Perspective tuning to a tactile, memorable metaphor
- Weak at: single-screen-of-truth center may feel cramped once you need to show more than a few lines of dialogue at once; monochrome amber limits how many distinct data states you can color-code without breaking the palette

### Best for
The primary operator view (PM at the console) where one project's state dominates attention and Perspective-switching is the main daily action.
